API 服务器

纯后端模式，不含网页界面

此 Stirling-PDF 实例正以 仅 API 模式运行：本次构建未包含网页界面。

打开 API 文档

想用网页界面？

如果你使用 Docker：

  • 你可能拉取了仅 API 镜像，或构建配置有问题
  • 请改用标准 Docker 镜像：stirlingtools/stirling-pdf:latest

如果你使用 JAR 文件：

  • 你下载的是 Stirling-PDF-server.jar，即不含界面的仅 API 版本
  • Download the full version from GitHub Releases 下载完整版：
  • Stirling-PDF.jar - 含界面的标准版
  • Stirling-PDF-with-login.jar - 含身份验证功能的版本

如果你从源码构建：

  • 用以下命令重新构建：./gradlew build -PbuildWithFrontend=true
  • 或将 /frontend 目录中的前端单独部署
